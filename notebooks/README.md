# Анализ Adult Income в pandas

В `adult_data_analysis.ipynb` выполнены:
- задание названий 15 столбцов;
- поиск пропусков, обозначенных ` ?`;
- подсчёт уникальных категорий;
- вычисление медианы и фильтрация по доходу/полу;
- заполнение пропусков модой.

Ноутбук содержит исторические выводы. Файл `adult.data` не входил в исходный репозиторий. Для повторного запуска нужно получить именно Adult Income из UCI, проверить условия источника и положить файл в `notebooks/data/adult.data`. Запускать Jupyter из папки `notebooks`.

Используйте окружение из `projects/diabetes/requirements-notebooks.txt`. Это отдельное упражнение по pandas, не обученная модель прогнозирования дохода.
