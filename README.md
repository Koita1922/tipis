## Быстрый запуск основного проекта

Из корня репозитория, Python 3.10+:

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r projects/diabetes/requirements.txt
python -m streamlit run projects/diabetes/app.py
```

Сохранённая модель входит в репозиторий. Переобучение:

```bash
python projects/diabetes/train.py
```

## Статус и ограничения

Это учебный проект, без коммерческого использования и клинической валидации. Результаты относятся к приложенному датасету.
Подробности исходного и исправленного экспериментов указаны в README проекта. Перестройка файлов и исправления воспроизводимости выполнены при подготовке портфолио с помощью ИИ; исходный эксперимент сохранён отдельно.

Происхождение и лицензия исходного CSV не были зафиксированы автором в первоначальном репозитории. Нельзя считать их подтверждёнными по одному имени файла; перед дальнейшим распространением данных нужно установить исходную страницу и условия использования.
